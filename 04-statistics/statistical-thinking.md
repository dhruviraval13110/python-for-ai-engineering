# Statistical Thinking

A statistic is useful only in context: define the population, sampling process, estimator, uncertainty and decision rule.

### Core checklist
- distribution and scale
- sample size and missingness
- independence assumptions
- point estimate + uncertainty
- effect size, not only p-value
- multiple comparisons when applicable

### Exercises
Simulate sampling distributions, bootstrap a mean/median, compare confidence intervals, and investigate how outliers alter mean vs median.
