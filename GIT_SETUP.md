# Git-ready setup

This repository is prepared to be pushed as a clean Git repository.

## First push

```bash
git init
git add .
git commit -m "feat: build Python for AI engineering portfolio"
git branch -M main
git remote add origin https://github.com/dhruviraval13110/python-for-ai-engineering.git
git push -u origin main
```

## Recommended ongoing commits

Use real changes only:

```text
feat: add numpy broadcasting examples
feat: implement churn training pipeline
test: add sales analytics validation tests
docs: expand pandas groupby guide
refactor: separate preprocessing from analysis
ci: tighten Python quality checks
```

Never rewrite history or create artificial commits merely to make the contribution graph look active.
