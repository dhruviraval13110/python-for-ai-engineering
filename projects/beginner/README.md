# Beginner Projects

Build small systems that prove fundamentals rather than collecting tutorial clones.

1. Expense intelligence CLI — Python, files, validation, testing.
2. Customer support ticket classifier — text preprocessing + baseline classifier.
3. Sales KPI explorer — Pandas + SQL + visualization.
4. Inventory reorder calculator — rules + uncertainty + reporting.
5. Student performance analysis — EDA + regression/classification.

**Definition of done:** README, data dictionary, reproducible run command, tests, limitations and one recorded failure analysis.
