# Notebooks

Notebooks are for exploration, visualization and experiments—not for hiding production logic.

## Standard notebook structure

1. Objective
2. Problem definition
3. Dataset and data dictionary
4. Imports/configuration
5. Data validation
6. EDA
7. Baseline
8. Experiment
9. Results
10. Error analysis
11. Conclusion
12. Next steps

Move reusable logic into `src/` once it stabilizes.
