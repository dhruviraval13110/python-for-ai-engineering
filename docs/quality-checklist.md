# Quality Checklist

## Technical
- [ ] Correctness checked
- [ ] Edge cases tested
- [ ] Complexity understood
- [ ] Dependencies documented

## ML
- [ ] Target and prediction time defined
- [ ] Baseline exists
- [ ] Split is defensible
- [ ] Leakage audit completed
- [ ] Metric matches decision
- [ ] Error analysis completed

## Engineering
- [ ] Reproducible environment
- [ ] Tests + lint
- [ ] Configuration separated from secrets
- [ ] Logging/observability appropriate
- [ ] README has run instructions

## Communication
- [ ] Claims backed by evidence
- [ ] Limitations visible
- [ ] No fabricated results
