# Computer Vision Engineering

This is a **deep course**, not a list of links. Each chapter is designed to take a learner from first principles to implementation, debugging, testing, interview discussion, and practical application.

## How to study

1. Read the mental model.
2. Type the code instead of copying it.
3. Predict output before execution.
4. Run the examples.
5. Break them intentionally.
6. Write tests.
7. Complete the exercise.
8. Explain the concept aloud.
9. Build the chapter project.
10. Mark the chapter complete only after you can reproduce the result.

## Interview standard

Every chapter includes conceptual, implementation, debugging, scaling, and production-review questions. Strong answers should include evidence: code, tests, measurements, or diagrams.

## Mastery standard

Do not treat page count as mastery. A topic is mastered when you can explain it, implement it, test it, debug it, and apply it to a realistic problem.
