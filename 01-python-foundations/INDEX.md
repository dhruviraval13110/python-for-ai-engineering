# Python Foundations — Curriculum Index

![learning loop](../assets/learning-loop.svg)

The existing `examples/` directory is the runnable source of truth for the early Python curriculum. This index turns it into a coherent engineering path.

| Stage | Existing material | Engineering extension |
|---|---|---|
| 01 | Variables / I/O / conversion | naming, invariants |
| 02 | Data types | data modeling |
| 03 | Operators | expressions and edge cases |
| 04 | Conditions | validation |
| 05 | Loops | iteration patterns |
| 06 | Functions | typing, contracts, reuse |
| 07 | OOP | composition, dataclasses |
| 08 | Exceptions | failure boundaries, logging |
| 09 | Files | serialization and safe I/O |
| 10 | Modules/packages | project architecture |
| 11 | Testing | pytest and test design |
| 12 | Tooling | linting, formatting, pre-commit |
| 13 | APIs / async | service integration |

### Mastery rule
Do not mark a topic complete because the syntax is familiar. Mark it complete when you can **write it, test it, explain it, and recover from a realistic bug**.
