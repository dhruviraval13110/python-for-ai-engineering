# Python Foundations — Zero to Professional

This folder is intentionally **course-sized**, not note-sized. The objective is to take a learner from zero Python knowledge to the point where they can build, test, debug, explain, and discuss Python professionally.

## Chapters

1. Mental model — objects, names, identity, mutability, runtime, exceptions
2. Syntax and types — expressions, strings, numbers, operators, slicing, comprehensions
3. Control flow — conditions, loops, iteration, enumerate, zip, debugging
4. Functions — parameters, scope, defaults, closures, decorators, testing
5. Data structures — lists, tuples, sets, dictionaries, copying, complexity
6. Files/modules/errors — pathlib, CSV, JSON, exceptions, logging, packages, environments
7. OOP — classes, composition, inheritance, protocols, dataclasses, dunder methods
8. Practical projects — progressively larger foundation projects
9. Interview bank — 140+ questions and follow-up drills

## Required learning loop

**Read → Type → Predict → Run → Break → Debug → Test → Explain → Build → Refactor**

A chapter is not complete because it was read. It is complete when the learner can reproduce the core behavior, explain why it works, diagnose a broken version, and use it in a small project.
