# Python Interview Preparation

## Round 1 — fundamentals

Explain the core vocabulary, assumptions and trade-offs without relying on buzzwords.

## Round 2 — coding / implementation

Write a small solution, state complexity, test edge cases and explain why the implementation is correct.

## Round 3 — debugging

Given a suspicious result, reproduce it, isolate the smallest failure, inspect assumptions and propose a regression test.

## Round 4 — system / case study

Define requirements → data → architecture → evaluation → failure handling → monitoring → cost/latency → security.

## Why questions

1. Why this approach?
2. Why not the simpler baseline?
3. What assumption could fail?
4. What would you measure next?
5. How would you know the system is degrading?
