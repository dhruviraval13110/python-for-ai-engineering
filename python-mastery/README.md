# Python Mastery — Zero to AI Engineer

This is the **deep-learning track inside `python-for-ai-engineering`**. It is designed for someone who starts with little or no Python and wants one structured repository that takes them through fundamentals, software engineering, data work, and Python used in machine learning.

> **Important:** No repository can magically make someone a master. Mastery comes from reading, running, breaking, rebuilding, testing, and shipping. This repository is designed to give you the complete path and practice system in one place.

## The learning loop

```text
LEARN → TYPE → RUN → BREAK → DEBUG → TEST → EXPLAIN → BUILD → REVIEW → REPEAT
```

## How to use this

For every chapter:

1. Read the mental model.
2. Type the examples instead of copy/pasting.
3. Change the examples until you can predict the output.
4. Complete the exercises without the solution.
5. Write tests.
6. Build the mini-project.
7. Explain the concept in your own words.
8. Add one improvement to your Git history.

## Mastery checkpoints

### Level 1 — Syntax
Can you write small programs from memory?

### Level 2 — Problem solving
Can you turn a problem statement into functions and data structures?

### Level 3 — Engineering
Can you validate inputs, handle failures, test behavior, type your code, and package it?

### Level 4 — Data
Can you load, clean, analyze, visualize, and validate a real dataset?

### Level 5 — ML
Can you build a reproducible training/evaluation pipeline without leakage?

### Level 6 — Production
Can you turn the workflow into a documented, tested, observable application?

## Interview readiness

Do not memorize one-line answers. For every concept, be able to explain:

- what it is;
- why it exists;
- how it works;
- when to use it;
- when not to use it;
- its trade-offs;
- a code example;
- a failure mode;
- an AI/ML application.

See the repository-level `INTERVIEW_PREPARATION.md` for the broader interview bank.
