# 04 Ml Pipeline

## Goal
Build a complete classification pipeline with preprocessing, cross-validation, evaluation, serialization, and an inference script.

## Required deliverables

- clean source package
- tests
- type hints
- CLI or reproducible entry point
- configuration
- README with architecture
- failure cases
- performance notes
- security considerations
- example input/output
- retrospective: what changed between v1 and v2

## Rule
Do not copy a tutorial implementation. Design the solution yourself, then compare your design with production alternatives.
