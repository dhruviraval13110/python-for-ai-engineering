# Python Mastery Exercise Bank

Do these without copying solutions. Each exercise has three levels: **build**, **break**, and **explain**.

## Beginner

1. Temperature converter with validation.
2. Number guessing game with attempt tracking.
3. Word-frequency counter.
4. Expense tracker using dictionaries.
5. CSV reader that validates required columns.

## Intermediate

6. Build a command-line todo manager.
7. Build a log parser that groups errors by type.
8. Implement a small package with tests and type hints.
9. Build a JSON-backed inventory service.
10. Build a reusable data-cleaning pipeline.

## Advanced

11. Implement a lazy data-processing pipeline with generators.
12. Build a plugin system using protocols or abstract base classes.
13. Build a concurrent URL-checking service.
14. Build a leak-safe ML training pipeline.
15. Package a Python CLI and run its test suite in GitHub Actions.

## Mastery rule

For every exercise submit: code, tests, README, complexity notes, failure cases, and a short explanation of design decisions.
