# Roadmap

## Phase 1 — Foundations
Python syntax, data structures, functions, OOP, errors, files, modules and tooling.

## Phase 2 — Data
NumPy, Pandas, cleaning, visualization, SQL and feature engineering.

## Phase 3 — Math + statistics
Linear algebra, calculus, probability, inference and experiments.

## Phase 4 — ML
Classical algorithms, evaluation, feature engineering, pipelines and error analysis.

## Phase 5 — Deep learning
Neural networks, backpropagation, CNNs, sequence models and transformers.

## Phase 6 — Applied AI
NLP, computer vision and generative AI.

## Phase 7 — LLM engineering
RAG, tools, agents, memory, structured outputs, evaluation and production constraints.

## Phase 8 — MLOps + deployment
Testing, experiment tracking, registries, APIs, Docker, CI/CD and monitoring.

## Phase 9 — Research + portfolio
Controlled experiments, flagship projects, technical writing and interview readiness.

**Rule:** do not mark a phase complete because the page was read. Mark it complete after producing evidence: code, tests, experiment notes and an explanation.
